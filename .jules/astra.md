
## 2024-05-24 - [Robust JSON Array Extraction from AI Responses]
**Learning:** Naive regex parsing (e.g. replacing ````json`) frequently fails to parse AI JSON responses if the AI output contains leading conversational preamble (e.g., "Here is the code you requested:\n```json\n[...]"). Also, lazy non-greedy regex matching (`/\[[\s\S]*?\]/`) can truncate nested JSON arrays at the first closing bracket.
**Action:** Always use `indexOf('[')` and `lastIndexOf(']')` (or `{` and `}`) to extract the bounds of the JSON block before running `JSON.parse()`.
\n## 2026-09-15 - [Handling Deterministic Model Refusals]\n**Learning:** When an AI model refuses a prompt due to safety ratings or content policies, returning a 500 status from the serverless proxy causes client-side retry wrappers to execute their full exponential backoff sequence. This results in unnecessary latency for the user and wasted API calls because the model's refusal is deterministic for that specific prompt.\n**Action:** Catch safety blocks specifically in backend proxy files (e.g. `api/gemini.ts`) and return a 400 Bad Request status code. This signals to client retry wrappers that the error is unrecoverable and should not be retried.
